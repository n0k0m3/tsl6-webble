TSL6 Web App

This page reads and writes the TSL6 settings over Web Bluetooth, and flashes a runtime image in boot mode. It makes no network calls except to load the bundled firmware image. It never sends the vendor server commands (AD, AE, AF), factory reset or car controls.

Connect

Not connected

Turn off Bluetooth on any phone that runs the vendor Mini App first. The module accepts one connection at a time.

The module sends blank settings until it accepts the BLE password. The password is the one you set in the vendor app (default 1234).

Status

Settings

Read the status first.

A write sends one A3 frame. It changes only the fields you edit and keeps every other bit as the module reported it. The module saves to flash at once. BLE signal strength takes effect after a module restart (unplug it for 10 s).

Firmware update

Flash the secured build (or another runtime) in the Flash tab. It restarts the module into boot mode and flashes in one step.

2. Flash

The bootloader waits only about 10 s for an update after the restart. So the page does it in one step: restart into boot mode, reconnect, start the update at once.

No status yet

If the page cannot reconnect by itself, tap Connect at once and pick TSL6-BOOT. The flash then starts by itself. If you miss the 10 s, the module goes back to normal. Start again.

72 pages take about 5–6 min in Bluefy at 20 bytes per write. After the update starts, the module stays in boot mode until a flash finishes. If a flash fails, connect to TSL6-BOOT and use the button below.
