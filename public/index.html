TSL6 BLE Recovery

Writes a runtime image to a TSL6 module stuck in its bootloader (BLE name TSL6-BOOT). The bootloader accepts only the runtime slot, so it cannot overwrite itself.

Use at your own risk. Not affiliated with the module maker or Tesla. Work only while the car is parked.
